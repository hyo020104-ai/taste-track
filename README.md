# TASTE TRACK

2026 대구대학교 시각디자인 전공 졸업전시 웹사이트. 정적 사이트(HTML 한 장 + assets)라 빌드 과정이 없다.

```
index.html   사이트 본체
assets/      폰트, 로고, 포스터, 지도, 사진, 영상
404.html     없는 주소 → 첫 화면
.nojekyll    GitHub Pages 가 파일을 그대로 내보내게
netlify.toml Netlify 배포 설정
```

GitHub Pages: Settings → Pages → Source `main` / `(root)`
